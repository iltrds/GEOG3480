# GEOG*3480 Midterm Prep

A study site for the GEOG*3480 (GIS and Spatial Analysis) Fall 2026 midterm, covering Units 1–6a and the Lab 1 and Lab 2 concepts.

- **Read**: condensed notes for each unit and lab, plus a formula sheet
- **Flashcards**: 164 cards, filterable by unit
- **Quizzes**: one multiple-choice quiz per unit, plus a mixed review
- **Practice exam**: 24 questions in the three-part midterm format with a 60-minute timer

The whole site is a single self-contained `index.html`, served with GitHub Pages. Progress is stored in your browser's local storage.
